# AI Receptionist Beauty Salon Gemma

This example demonstrates an AI-powered receptionist for a beauty salon, simulating the concept discussed in the article. It uses Google's Generative AI API (Gemini Pro) to handle customer inquiries, manage appointment requests, and answer frequently asked questions, acting as a smart assistant named Gemma. The system prompt defines the AI's persona and rules, showcasing how an LLM can be tailored for specific domain tasks.

## Language

`python`

## How to Run

1. Install the required library: `pip install google-generativeai`
2. Set your Google Generative AI API key as an environment variable: `export GOOGLE_API_KEY="YOUR_API_KEY"` (Replace YOUR_API_KEY with your actual key)
3. Run the Python script: `python main.py`
